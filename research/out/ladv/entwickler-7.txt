 LADV API KYEs
 Derzeit keine neuen API KEYs
 Derzeit werden keine neuen API KEYs erstellt, da wir einige notwendige Anpassungen und Erweiterungen an unserer API vornehmen. Sobald dieser Hinweis entfernt ist, können neue API KEYs angefragt werden.
 Zielgruppe
 Die LADV API richtet sich an Athleten, Vereine, Kreise, Bezirke und Verbände, die auf ihre Daten auf LADV zugreifen möchten. Der Zugriff muss im Vorfeld von Verantwortlichen der Organisationseinheit freigegeben werden.
 Zugriff für APPs, Webseiten oder andere Projekte ist i. d. R. nicht möglich.
 Für den Zugriff auf die LADV API ist ein API KEY notwendig.
 API KEY Beantragen
 Wenn Sie als berechtigte Organisationseinheit die API nutzen möchten, kontaktieren Sie uns per Email oder über das Kontaktformular mit dem Betreff „API KEY". Bitte geben Sie bei Ihrer Anfrage an, für welche Organisationseinheit und welchen Zweck Sie den API-Zugriff benötigen.
 Aktuell werden keine API KEYs erstellt.
